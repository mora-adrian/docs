On Mac use <Key>⌘</Key>. On Windows and Chromebook use <Key>Ctrl</Key>.

## Anywhere

| Keys | Does |
| --- | --- |
| <Key>⌘</Key> <Key>K</Key> | Opens the **command palette** to search repair orders, people, companies, vehicles, and pages. |
| <Key>⌘</Key> <Key>B</Key> | Shows or hides the sidebar. |
| <Key>Esc</Key> | Closes the drawer, dialog, or menu that is open. |

## Writing

| Keys | Does |
| --- | --- |
| <Key>⌘</Key> <Key>Enter</Key> | Sends a note, email, or text; saves an edit form. |

## Boards and Long Lists

| Keys | Does |
| --- | --- |
| Arrow keys | Scrolls the board. |
| <Key>⇧</Key> <Key>O</Key> | Collapses or expands all folders on the Files tab and all sections in a Rivet review. |

## Repair Order Calendar Tab

| Keys | Does |
| --- | --- |
| Left / Right arrows | Moves one day. |
| Up / Down arrows | Moves one week. |

<Tip>
The fastest way around Kinetic is <Key>⌘</Key> <Key>K</Key>. Type a customer's name, a repair order number, or a VIN and press Enter. The palette finds things; it does not create them.
</Tip>
