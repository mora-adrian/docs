Four boards organize every repair order by where the job is in its lifecycle. Each shows a live count in the sidebar, and each offers the same set of views and controls.

## The four boards

| Board | Screen title | What it holds |
| --- | --- | --- |
| Opportunity | **Opportunities** | Leads and estimates — jobs quoted but not yet authorized or dropped off. |
| Repair | **Repairs** | Vehicles actively in the shop: authorized, in repair, waiting on parts, in QC (quality control). |
| Close | **Close & Deliver** | Ready for pickup, delivered, or awaiting payment and paperwork. |
| Enrichment | **Enrichment** | Post-repair follow-up: surveys, reviews, and record completion. |

A repair order appears on exactly one board. It moves when its status changes — by your hand on the board or record, or automatically when a CCC ONE event maps to a new status.

## Views

Every board offers the same views. Switch between them from the toolbar.

### Table view

A dense, sortable grid. The repair order number column is pinned and cannot be hidden. Everything else is configurable.

**Columns** (toggle under the **Columns** menu):

| Column | Contents |
| --- | --- |
| Repair order # | The shop-assigned number (always visible, pinned). |
| Customer | Primary person or company. |
| Vehicle | Year, make, model. |
| VIN | Vehicle identification number. |
| Insurer | The paying insurer, when it is a claim job. |
| Claim # | The claim number. |
| Estimate | Current estimate amount. |
| Received | Payments received so far (from the ARW tab). |
| Status | The current workflow status pill. |
| Team | Assigned staff summary. |
| Client Advocate | The assigned advocate. |
| Repair Planner | The assigned planner. |
| Technician | The assigned technician. |
| Days in Shop | Days since arrival. |
| Arrival | Arrival date. |
| Target Date | The promised out date. |
| Appointment | Next scheduled appointment. |
| Total Loss | Whether the job is flagged a total loss. |
| Released | Whether the vehicle has been released. |
| Customer Approval | Customer approval state. |
| Insurance Approval | Insurance approval state. |
| Outcome likelihood | The calculated repairability score. |
| Last communication | When the customer last heard from the shop. |

The **Columns** menu also toggles customer and vehicle avatars. Column sizing and visibility persist per user.

### Board view

Cards in one column per status. Drag a card to another column to change status — the change is real and audited. A status pill dot shows each card's meaning tone:

| Tone | Meaning |
| --- | --- |
| Blue | **Needs** — the ball is in your court. |
| Amber | **Waiting** — blocked on someone or something else. |
| Green | **On track** — progressing normally. |
| Red | **Late** — behind, blocked, or lost. A record past its target date reads as late regardless of status. |

A "No status" column catches records that have not been placed yet. Right-click or use the card's **Move to** action as an alternative to dragging.

### Timeline view

Repair orders laid out on a time axis — arrival to target — so load and overlap are visible. Zoom in and out to change the horizon.

### Production lanes

A lane view grouped for the production meeting: records organized so capacity, assignment, and blockers are readable at a glance.

## Filters

Select **Filters** on any board to open the filter panel. A badge on the button shows how many filters are active; the **X** clears them all. Active filters apply to the current view.

| Filter | Type | Notes |
| --- | --- | --- |
| Client Advocate | Pick list of employees | Who owns the customer relationship. |
| Repair Planner | Pick list of employees | Who plans the work. |
| Technician | Pick list of technicians | Who wrenches. |
| Status | Pick list of your shop's configured statuses | Narrows to one status. |
| Outcome likelihood | Pick list | Repairability score range. |
| Total Loss | Yes / No / Any | |
| Released | Yes / No / Any | Vehicle released to customer. |
| Customer Approval | Yes / No / Any | |
| Insurance Approval | Yes / No / Any | |
| Arrival | Date range | Inclusive from/to. |
| Target Date | Date range | Inclusive from/to. |
| Days in Shop | Min–max slider | The top stop means "any". |

## Search and sorting

- The **search field** matches repair order number, customer, VIN, and claim number.
- Column headers sort ascending/descending; counts and totals always come from the server, so a filtered table's numbers stay truthful.

## The record drawer

Click any card or row once for the **drawer**: a read-only peek showing identity (repair order number, customer, vehicle, insurer and claim), status and days in status, target date confidence, parts received percentage, outcome likelihood, expected insurance payout, assigned seats, survey stage when a survey exists, and the five most recent activity items. Its single action opens the full record — see [Repair orders](/daily-work/repair-orders).
