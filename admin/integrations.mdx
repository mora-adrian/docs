## CCC ONE

CCC ONE is the shop's estimating and production system, and the **source of truth** for repair orders. Kinetic receives repair orders, estimates, parts, and production stages from it.

- Kinetic cannot create a repair order. If one is missing, check CCC ONE.
- Customer details, VIN, and dates are corrected in CCC ONE.
- Setup and reconnection are handled by Kinetic support; contact them if repair orders stop updating.
- If CCC ONE sends a production stage Kinetic has no rule for, the Activity tab shows **CCC status unmapped**.

## Texting line

The shop's texting number. Status shows in [Messaging settings](/admin/messaging-settings): **Configured**, **Not configured**, or **Unable to check**.

## Phone system

Connect it in [Shop settings](/admin/shop-settings#phone-system) so calls appear on repair orders. **Needs reconnect** means the link has lapsed.

## Mailboxes

Each person connects their own mail account (Google or Microsoft) in [Preferences](/admin/personal-preferences#mailbox). Kinetic reads it; it does not send from it or delete from it. Connecting a mailbox is also what turns on [Email review](/communicate/email-review).

## Map

The [tow map](/schedule/tow-planning#the-map) uses a mapping service. If it is not set up, the page says **Mapping isn't configured for this shop.** Everything else keeps working.

## Checking health

| Sign | Likely cause | Fix |
| --- | --- | --- |
| Repair orders stop updating | CCC ONE connection | Contact support |
| **Needs reconnect** on the phone system | Connection lapsed | Reconnect in Shop settings |
| Texting **Unable to check** | Temporary | Wait a minute and reload; contact support if it persists |
| No Email review item at all | No mailbox connected | Connect in Preferences |
